## Google Docs

1. No Google Drive: **Novo › Nova pasta** → `{{folder_name}}`. Se for sobre alguém que você lidera, compartilhe só com essa pessoa.
2. Abra qualquer Documento Google e ative **Ferramentas › Preferências › Ativar Markdown** (uma vez).
3. Para cada documento: **Novo › Documentos Google**, copie o arquivo Markdown inteiro (ou o bloco de código) e clique com o botão direito › **Colar do Markdown**. Dê ao documento o nome do arquivo, sem o `.md`.
4. **Links:** abra cada documento, **Compartilhar › Copiar link**, e troque o nome do arquivo na tabela de documentos do Hub de Carreira pelo link. Aponte cada "← Voltar ao Hub de Carreira" para o Hub.
5. **Planilha:** baixe a planilha de Avaliação de Trilha do Kit Manual (Releases do repositório → `sheets/`), suba na pasta e **Abrir com › Planilhas Google**. Ou use a versão em texto incluída aqui.
6. Marque um **1:1 recorrente a cada duas semanas** com o link do Hub no convite.

## Microsoft Word (OneDrive / SharePoint)

1. No OneDrive ou SharePoint: **+ Adicionar novo › Pasta** → `{{folder_name}}`. Se for sobre alguém que você lidera, compartilhe só com essa pessoa.
2. O Word não cola Markdown de forma confiável. Para cada documento, mostre o Markdown **renderizado** primeiro — abra o `.md` numa pré-visualização de Markdown (por exemplo o GitHub, a pré-visualização do VS Code, ou o chat onde você recebeu), selecione todo o texto renderizado, copie e cole num novo documento do Word. Títulos, listas, negrito e tabelas vêm junto.
3. Alternativa mais rápida: baixe os `.docx` prontos do Kit Manual (Releases do repositório → `word/`) e preencha os campos escritos entre chaves duplas (como *person_name*) com **Página Inicial › Substituir**.
4. **Links:** selecione cada arquivo no OneDrive › **Copiar link**, e troque o nome do arquivo na tabela do Hub de Carreira pelo link.
5. **Planilha:** suba o `.xlsx` da Avaliação de Trilha do Kit Manual; ele abre no Excel com tudo funcionando. Ou use a versão em texto incluída aqui.
6. Marque um **1:1 recorrente a cada duas semanas** no Outlook com o link do Hub no convite.
