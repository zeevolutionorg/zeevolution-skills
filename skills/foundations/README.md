# Foundations

Shared building blocks used by every category. A category never re-implements these.

| Skill | Kind | What it does |
|---|---|---|
| [setup-zeevolution-skills](setup-zeevolution-skills/SKILL.md) | user-invoked | One-time defaults: name, discipline, platform, folder, language, ladder |
| [cloud-workspace](cloud-workspace/SKILL.md) | model-invoked | Create and link documents / spreadsheets in Google, Microsoft 365 or as files; render templates; build sheets from specs |
| [doc-templates](doc-templates/SKILL.md) | model-invoked | Placeholders, tip anatomy, self vs lead wording, languages |
| [disciplines](disciplines/SKILL.md) | model-invoked | Vocabulary and examples for engineering, data science, design, product |
