## Google Docs

1. In Google Drive: **New › New folder** → `{{folder_name}}`. If it's about someone you lead, share it only with them.
2. Open any Google Doc and turn on **Tools › Preferences › Enable Markdown** (once).
3. For each document: **New › Google Docs**, then copy the whole Markdown file (or code block) and right-click › **Paste from Markdown**. Name the doc like the file, without the `.md`.
4. **Links:** open each doc, **Share › Copy link**, and replace its file name in the Career Hub's documents table with the link. Point every "← Back to Career Hub" link at the Hub.
5. **Spreadsheet:** download the Ladder Assessment spreadsheet from the Manual Kit (repository Releases → `sheets/`), upload it to the folder and **Open with › Google Sheets**. Or use the text version included here.
6. Book a recurring **1:1 every two weeks** with the Hub link in the invite.

## Microsoft Word (OneDrive / SharePoint)

1. In OneDrive or SharePoint: **+ Add new › Folder** → `{{folder_name}}`. If it's about someone you lead, share it only with them.
2. Word doesn't paste Markdown reliably. For each document, show the Markdown **rendered** first — open the `.md` file in a Markdown preview (for example GitHub, VS Code preview, or the chat where you received it), select all of the rendered text, copy, and paste into a new Word document. Headings, lists, bold text and tables come along.
3. Faster alternative: download the ready-made `.docx` files from the Manual Kit (repository Releases → `word/`) and fill in the fields written between double curly braces (like *person_name*) with **Home › Replace**.
4. **Links:** select each file in OneDrive › **Copy link**, and replace its file name in the Career Hub's table with the link.
5. **Spreadsheet:** upload the Ladder Assessment `.xlsx` from the Manual Kit; it opens in Excel with everything working. Or use the text version included here.
6. Book a recurring **1:1 every two weeks** in Outlook with the Hub link in the invite.

## Notion, Confluence, Obsidian

Paste or import each `.md` file directly — these tools read Markdown. Then do the links and the bi-weekly as above.
